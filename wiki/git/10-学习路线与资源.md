# Git 学习路线与资源

## 摘要
由浅入深的 Git 学习路径：先会用基础命令，再理解分支与远程，最后掌握变基、冲突与工程化工作流；附权威资料与可视化工具。

## 正文

### 推荐路线
1. **上手**：理解 [[02-Git核心概念]] 与 [[03-Git基础命令]]，能在本地完成 init/add/commit。
2. **协作**：掌握 [[04-Git分支模型]] 与 [[05-Git远程协作]]，能 fork/PR、push/pull。
3. **进阶**：学 [[06-Git变基与历史改写]]、[[08-Git冲突解决]]，处理真实协作冲突。
4. **工程化**：落地 [[09-Git工作流与最佳实践]]，规范提交、配置钩子。

### 权威资料
- **Pro Git（官方书，中文）**：https://git-scm.com/book/zh/v2 — 最系统、最权威。
- **Git 官方文档**：https://git-scm.com/docs — 每条命令的参数说明。
- **可视化学习**：https://learngitbranching.js.org — 交互式分支练习。

### 常用速查
- 本主题索引 [[git-index]] 串联全部条目。
- 日常卡壳时用 `git help <command>` 查看内置手册。
