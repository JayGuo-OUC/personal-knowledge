# Git 概览1

## 摘要
Git 是一款**分布式版本控制系统**，用于追踪文件随时间的变化、支持多人协作开发，并能随时回溯到任意历史版本。其核心优势在于「分布式」「快照存储」「廉价分支」与「完整性校验」。

## 正文

### 什么是版本控制
版本控制（VCS）记录文件的历史变更，让你能够：回滚到旧版本、对比差异、多人并行开发而不互相覆盖。没有版本控制时，人们只能靠 `v1.txt`、`v2_final.txt`、`v2_final_真的最终.txt` 手工管理，极易混乱。

### 集中式 vs 分布式
- **集中式（SVN、CVS）**：单一中央服务器保存全部历史，开发者需联网才能提交/查看历史；服务器宕机即全体停摆。
- **分布式（Git、Mercurial）**：每个开发者本地都有一份完整仓库（含完整历史），离线也能提交与查看；中央仓库（如 GitHub）只是「大家都认的一个同步点」，而非单点。

### Git 的核心能力
1. **快照而非差异**：Git 每次提交记录的是文件系统的「快照」，而非逐行 diff，因此分支、回滚、比对都非常快。
2. **廉价分支**：创建分支只是新建一个指针，几乎零成本，鼓励「一条分支干一件事」。
3. **完整性校验**：每个对象用 SHA-1 哈希标识，内容一旦写入不可篡改，可检测损坏。
4. **分布式**：本地仓库自洽，可脱离网络工作，后续再与远端同步。

### 典型工作流一句话
`工作区修改 → git add 暂存 → git commit 提交 → git push 推到远端`，协作时通过分支与合并组织并行工作。
