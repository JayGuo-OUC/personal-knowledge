# 学习路线与资源

## 学习目标
- 拿到一条可执行的云原生学习路线图
- 知道值得考的认证与可读的书/课/社区
- 知道如何继续扩充本知识库

## 推荐学习路线（由浅入深）

```
阶段 1 · 基础
  云原生概览 → CNCF 全景 → 容器基础 → Docker 实战
阶段 2 · 编排核心
  K8s 核心概念 → K8s 架构 → Pod 与工作负载 → Service 与网络 → 存储与配置 → 控制器原理
阶段 3 · 架构进阶
  微服务 → 服务网格 → 可观测性 → CI/CD → Serverless → 安全
阶段 4 · 综合
  最佳实践 → 动手做项目（搭一套含监控+网格的 K8s 应用）
```

## 认证（按需）
- **CKA（Certified Kubernetes Administrator）**：运维管理。
- **CKAD（Certified Kubernetes Application Developer）**：应用部署。
- **CKS（Certified Kubernetes Security）**：安全专项。
- 云厂商认证：ACK / EKS / GKE 相关。

## 书籍与文档
- Kubernetes 官方文档（kubernetes.io/docs）
- 《Kubernetes in Action》Marko Lukša
- 《云原生模式》Cornelia Davis
- 《微服务设计》Sam Newman
- CNCF 技术雷达与白皮书

## 动手环境
- 本地：minikube / kind / Docker Desktop
- 云平台免费额度：ACK / EKS / GKE
- 在 [[04-Docker实战]] 之后即可用 kind 起一个本地集群练手。

## 社区
- CNCF / KubeCon、Kubernetes Slack、云原生社区公众号、GitHub CNCF 组织。

## 如何继续扩充本知识库（LLM-Wiki 流程）
1. 把新资料（文章、PDF）放进 `raw/`（不可变）。
2. 让我（AI）阅读后，更新相关 `wiki/` 页面、维护 `wiki/index.md` 与 `wiki/log.md`。
3. 把有价值的问题回答沉淀成新笔记，消除孤儿页、补全交叉引用。
4. 定期做 **Lint 体检**：查矛盾、过期、缺失链接（见 [[CLAUDE]]）。
