# 容器技术基础

## 学习目标
- 说清容器是什么、与虚拟机的区别
- 理解 Namespace 与 Cgroups 两大基石
- 理解镜像分层与联合文件系统

## 核心概念

**容器** 是一种轻量、可移植、自包含的软件打包技术：把应用及其依赖打包在一起，在隔离的用户空间中运行。

## 详细说明

### 容器 vs 虚拟机
| 维度 | 虚拟机 | 容器 |
|------|--------|------|
| 隔离级别 | 操作系统级（Hypervisor） | 进程级（内核 Namespace） |
| 启动速度 | 秒~分钟 | 毫秒~秒 |
| 体积 | GB 级 | MB 级 |
| 密度 | 低 | 高 |

### 两大 Linux 基石
1. **Namespace（命名空间）**：实现资源视图隔离——PID、网络、挂载、UTS、IPC、User 等互相不可见。
2. **Cgroups（控制组）**：实现资源限制与统计——CPU、内存、IO 配额。

### 镜像与分层
- 容器**镜像**是只读模板，由多层（layer）叠加而成。
- 使用**联合文件系统（OverlayFS）** 把多层合并为单一视图。
- 同层可复用，节省存储与传输（见 [[04-Docker实战]]）。

### 仓库（Registry）
镜像存放在镜像仓库，如 Docker Hub、Harbor、GitHub Container Registry。

## 实践示例
查看容器隔离本质（Linux）：
```bash
# 以独立 PID/Mount/Network 命名空间运行一个 shell
unshare --pid --mount --net --fork bash
```

## 常见问题
**Q：容器是轻量虚拟机吗？**
A：不是。容器共享宿主机内核，只是被 Namespace/Cgroups 隔离的进程。
