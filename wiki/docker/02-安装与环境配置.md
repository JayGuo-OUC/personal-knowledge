# 02 安装与环境配置

## 摘要

不同操作系统装 Docker 的方式不同。Windows 推荐 Docker Desktop + WSL2 后端；Mac 用 Docker Desktop；Linux（Ubuntu/CentOS）直接装 Docker Engine。本文给各平台可照做的步骤，并配置**国内镜像加速器**解决拉镜像慢的问题。

## 正文

### 1. 版本与组件说明

- **Docker Desktop**：Windows / Mac 的图形化一键安装包，内含 Docker Engine + Compose + 镜像构建工具，适合开发和入门。
- **Docker Engine**：Linux 上的纯命令行引擎，服务器常用。
- **Docker Compose v2**：现已内置于 `docker compose` 子命令（注意是空格不是横杠），无需单独装。

### 2. Windows 安装（推荐 WSL2 后端）

前置：Windows 10/11 专业版或家庭版（家庭版走 WSL2 路线，已支持）。

```powershell
# 1) 用管理员 PowerShell 启用 WSL 与虚拟机平台
wsl --install
# 重启后，把 WSL2 设为默认
wsl --set-default-version 2

# 2) 从官网下载 Docker Desktop 安装包并安装：
#    https://www.docker.com/products/docker-desktop/
#    安装时勾选 "Use WSL 2 instead of Hyper-V"（默认即勾选）
```

安装后在 Docker Desktop 设置里确认：`Settings → General → Use the WSL 2 based engine` 已开启；`Settings → Resources → WSL Integration` 把你的 Linux 发行版打开，这样 Docker 命令可在 WSL 终端直接用。

### 3. macOS 安装

- Apple 芯片（M1/M2/M3）：下载 **Apple Silicon** 版 Docker Desktop。
- Intel 芯片：下载 **Intel Chip** 版。
- 拖进「应用程序」即可。验证：

```bash
docker --version
docker run hello-world
```

### 4. Linux 安装（Ubuntu 为例）

```bash
# 卸载旧版本
sudo apt-get remove docker docker-engine docker.io containerd runc

# 安装依赖与 Docker 官方源
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 让当前用户免 sudo（可选但强烈推荐）
sudo usermod -aG docker $USER
# 重新登录终端后生效
```

> CentOS / Rocky / Alma 把 apt 换成 dnf 即可，命令类似（`sudo dnf install docker-ce docker-ce-cli ...`）。

### 5. 验证安装

```bash
docker --version          # 看版本
docker info               # 看引擎详情（含镜像加速是否生效）
docker run hello-world    # 跑通说明装好了
```

### 6. 配置国内镜像加速器（重要）

国内直连 Docker Hub 很慢甚至超时，务必配置镜像源。

**Docker Desktop（Win/Mac）**：`Settings → Docker Engine`，在 JSON 里加 `registry-mirrors`：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com"
  ]
}
```

改完点 **Apply & Restart**。

**Linux**：编辑 `/etc/docker/daemon.json`（没有就新建）：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://hub-mirror.c.163.com"
  ]
}
```

然后：

```bash
sudo systemctl daemon-reload
sudo systemctl restart docker
docker info | grep -A3 Mirrors   # 确认生效
```

> 镜像源会过期/变动，若发现拉不动可换用其它公开镜像或公司内网私有仓库（见 [[13-Docker-Hub与私有仓库]]）。

### 7. 常见问题

- **Linux 上 `permission denied`**：没加 docker 用户组，执行「让当前用户免 sudo」后重登；临时可用 `sudo docker ...`。
- **WSL2 下 `docker: command not found`**：Docker Desktop 的 WSL Integration 没开，去设置打开对应发行版。
- **Windows 家庭版装不了 Hyper-V**：用 WSL2 后端即可，无需 Hyper-V。
