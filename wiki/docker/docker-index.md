# Docker 学习路径总览（MOC）

> 一份从零到生产的 Docker 完整课程。按「概念 → 基础操作 → 镜像构建 → 数据网络 → 编排 → 生产实战」的顺序学习，每篇之间用 `[[双链]]` 相连，建议从头到尾依次阅读。

## 这门课能让你做到什么

学完你应当能够：**独立安装配置 Docker**、**理解镜像/容器/仓库三大核心对象**、**用 Dockerfile 把任意应用打包成镜像**、**用 Volume 与网络解决持久化与互通问题**、**用 Docker Compose 编排多容器应用**、并**掌握生产环境的安全与排错要点**。

## 学习路线（四阶段）

```
阶段一 · 认知与准备
  ├─ 01 容器与 Docker 入门        （是什么、为什么、与虚拟机的区别）
  ├─ 02 安装与环境配置            （Win/Mac/Linux、WSL2、镜像加速）
  └─ 03 镜像·容器·仓库 核心概念   （三大对象的生命周期与关系）

阶段二 · 日常操作
  ├─ 04 镜像操作实战              （pull/images/rmi/tag/save/load）
  ├─ 05 容器生命周期管理          （run/ps/start/stop/rm/inspect）
  └─ 06 容器内操作与调试          （exec/logs/cp/stats）

阶段三 · 构建与连通
  ├─ 07 Dockerfile 完全指南       （全部指令 + 多阶段构建 + 优化）
  ├─ 08 构建你的第一个镜像        （Node/Python/Java 实战）
  ├─ 09 数据持久化（Volume/挂载） （数据为什么丢、怎么不丢）
  └─ 10 容器网络                  （bridge/host/自定义网络/端口映射）

阶段四 · 编排与生产
  ├─ 11 Docker Compose 编排       （单文件定义多容器）
  ├─ 12 实战：全栈应用编排        （web + db + redis 一把拉起）
  ├─ 13 Docker Hub 与私有仓库     （推送/拉取/自建 registry/扫描）
  ├─ 14 生产环境最佳实践          （安全/资源限制/健康/CI-CD）
  └─ 15 常见问题与排错            （故障清单 + FAQ）
```

## 前置知识

- 基本命令行操作（Linux/Mac 的 Terminal 或 Windows 的 PowerShell/WSL2）。
- 了解一门编程语言或至少「应用 = 代码 + 依赖 + 配置」的概念即可，无需深入。
- 想直接动手可跳过理论，但从 [[03-镜像容器仓库核心概念]] 起建议按顺序。
