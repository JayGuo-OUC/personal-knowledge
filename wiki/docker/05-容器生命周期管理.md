# 05 容器生命周期管理

## 摘要

容器的完整生命周期：`创建 → 运行 → 暂停/停止 → 删除`。本文覆盖最常用也最重要的 `docker run` 参数，以及启停、查看、删除、查看详情等日常操作。

## 正文

### 1. 生命周期状态

```
docker create  ──▶ created ──▶ docker start ──▶ running
                                            │
                              docker pause  │  docker stop / kill
                                            ▼         │
                                         paused    stopped ──▶ docker rm ──▶ deleted
```

- `docker create`：仅创建不启动。
- `docker run` = `create` + `start`，最常用。
- 前台进程退出 → 容器进入 `stopped`（Exited），**不会自动删除**。

### 2. 最核心命令：docker run

```bash
docker run [OPTIONS] IMAGE[:TAG] [COMMAND] [ARG...]
```

高频选项：

| 选项 | 作用 |
|------|------|
| `-d` | 后台（detached）运行，返回容器 ID |
| `--name <n>` | 给容器起名（否则随机名） |
| `-p 8080:80` | 端口映射 `宿主:容器` |
| `-P` | 随机映射镜像 EXPOSE 的所有端口 |
| `-v` / `--volume` | 挂载数据卷或目录（见 [[09-数据持久化Volume与挂载]]） |
| `-e KEY=VAL` | 注入环境变量 |
| `--env-file .env` | 从文件批量注入环境变量 |
| `--network <n>` | 指定网络（见 [[10-容器网络]]） |
| `-it` | `-i` 交互 + `-t` 伪终端，常用于「进容器」 |
| `--rm` | 容器停止后**自动删除**（临时调试神器） |
| `--restart always` | 宿主机重启/容器退出后自动拉起（生产守护） |
| `--memory 512m` | 限制内存（见 [[14-生产环境最佳实践]]） |
| `--cpus 1` | 限制 CPU 核数 |

示例：

```bash
# 后台跑一个带名字、端口映射、自动重启的 nginx
docker run -d -p 8080:80 --name web --restart always nginx:1.27

# 临时调试一个 python 容器，退出即删
docker run --rm -it python:3.12-slim bash
```

### 3. 查看容器

```bash
docker ps                 # 只看运行中的
docker ps -a              # 看所有（含已停止）
docker ps -q              # 只看 ID（便于脚本批处理）
docker ps --filter "name=web"   # 按条件过滤
```

### 4. 启停与重启

```bash
docker start web          # 启动已停止的
docker stop web           # 优雅停止（发 SIGTERM，默认等 10s 再 SIGKILL）
docker stop -t 30 web     # 给 30s 优雅退出时间
docker restart web        # 重启
docker pause web         # 暂停（冻结进程，不释放资源）
docker unpause web       # 恢复
docker kill web          # 强制杀（SIGKILL，不等优雅退出）
```

> 生产上用 `stop` 而非 `kill`，给应用留「存盘/关闭连接」的优雅退出窗口。

### 5. 删除容器

```bash
docker rm web             # 删已停止的
docker rm -f web          # 强制删（先 stop 再 rm）
docker rm -f $(docker ps -aq)   # 删掉所有容器（危险，谨慎）
```

### 6. 查看容器详情

```bash
docker inspect web        # 完整 JSON：IP、挂载、配置、状态
docker inspect -f '{{.NetworkSettings.IPAddress}}' web  # 用 Go 模板取字段
docker top web            # 看容器内运行的进程
docker stats web          # 实时看 CPU/内存/网络/IO 占用
```

`docker stats` 是排查「容器吃资源」的第一现场工具。

### 7. 导出/导入容器文件系统（少用）

```bash
docker export web -o web.tar      # 把容器当前文件系统打成 tar
docker import web.tar myimage:from-container  # 导入成镜像
```

> `export/import` 会**丢失镜像历史层与元数据**（ENTRYPOINT/ENV 等），仅适合应急搬运；日常用 [[04-镜像操作实战|save/load]] 或重新 build。
