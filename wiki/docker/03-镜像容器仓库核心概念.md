# 03 镜像·容器·仓库 核心概念

## 摘要

Docker 世界有三大核心对象：**镜像（Image）** 是只读模板，**容器（Container）** 是镜像运行起来的可写实例，**仓库（Registry）** 是存放和分发镜像的地方。理解它们的生命周期与相互关系是后续所有操作的基础。

## 正文

### 1. 三者的关系

```
Registry（仓库）
   │  存/取
   ▼
Image（镜像，只读模板）   ── docker run ──▶  Container（容器，可读写实例）
   │                                            │
   │  docker commit / docker build              │ docker stop/rm
   ▼                                            ▼
 新镜像                                      销毁，未提交改动丢失
```

一句话：**仓库里下载镜像，镜像跑起来变成容器，容器的改动可提交成新镜像。**

### 2. 镜像（Image）

- **本质**：分层（layer）的只读文件系统。每一层是 Dockerfile 里一条指令产生的一次文件系统变更。
- **只读**：镜像本身不能被修改；容器在它上面加一层「可写层」来记录改动。
- **分层共享**：多个镜像可共用基础层（如都基于 `ubuntu:22.04`），节省磁盘。
- **标识**：通过 `仓库名:标签` 引用，如 `nginx:1.27`、`python:3.12-slim`；不带标签默认 `:latest`（**生产上不要用 latest**，无法回滚）。

用 [[04-镜像操作实战]] 学习镜像的增删改查。

### 3. 容器（Container）

- **本质**：镜像 + 一个可写层（container layer）+ 运行中的进程。
- **状态机**：`created → running → paused/stopped → deleted`。
- **可写层**：容器里 `apt install`、改文件都写在这一层；容器删除，这层随之消失（这就是数据会「丢」的原因，解决见 [[09-数据持久化Volume与挂载]]）。
- **进程模型**：一个容器通常只跑一个前台进程（PID 1）；进程退出，容器就停止。

> 关键认知：**容器是「一次性」的**。它不是虚拟机，不要想着「进去配一配以后一直用」——配置应写进 [[07-Dockerfile完全指南|Dockerfile]]，用镜像固化。

### 4. 仓库（Registry）

- **Docker Hub**：公共默认仓库，docker.io，海量官方/社区镜像。详见 [[13-Docker-Hub与私有仓库]]。
- **镜像地址格式**：`[仓库地址/]项目名/镜像名:标签`。省略仓库地址即 Docker Hub；如 `registry.internal:5000/myapp:1.0`。
- **拉取 vs 推送**：`docker pull` 下载，`docker push` 上传（需登录且通常推到自己的命名空间）。

### 5. 一个把三者串起来的例子

```bash
# 1) 从仓库（Docker Hub）拉镜像
docker pull nginx:1.27

# 2) 用镜像启动容器
docker run -d -p 8080:80 --name web nginx:1.27

# 3) 进容器改点东西（改的是可写层，不是镜像）
docker exec -it web bash
  > echo "hello" > /usr/share/nginx/html/test.html
  > exit

# 4) 把改动提交成新镜像（不推荐日常用，仅演示）
docker commit web my-nginx:with-test

# 5) 把新镜像推到仓库（演示，需 docker login）
docker tag my-nginx:with-test yourname/my-nginx:with-test
docker push yourname/my-nginx:with-test

# 6) 清理：停并删容器（可写层丢失，但镜像 my-nginx 还在）
docker stop web && docker rm web
```

> 日常**不要**用 `docker commit` 固化改动——那不可复现。正确做法是改 [[07-Dockerfile完全指南|Dockerfile]] 后重新 `docker build`。

### 6. 概念自检

- 镜像和容器的本质区别？→ 只读模板 vs 加了可写层的运行实例。
- 为什么容器删了数据可能没？→ 改动只在可写层，删容器即可写层消失。
- `:latest` 有什么隐患？→ 不知道具体版本，无法稳定回滚。
