# 08 构建你的第一个镜像

## 摘要

光看指令不够，动手才有体感。本文用 Node、Python、Java（Spring Boot）三个真实例子，从「写应用 → 写 Dockerfile → build → run」走完一遍，并演示多阶段构建把体积压下来。

## 正文

### 例 1：Node.js 应用

`app.js`：

```js
const http = require('http');
const server = http.createServer((req,res)=>{
  res.end('Hello from Docker!\n');
});
server.listen(3000, ()=>console.log('listening on 3000'));
```

`Dockerfile`：

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --omit=dev
COPY . .
EXPOSE 3000
CMD ["node","app.js"]
```

构建运行：

```bash
docker build -t node-demo:1.0 .
docker run -d -p 3000:3000 --name node-demo node-demo:1.0
curl http://localhost:3000     # 输出 Hello from Docker!
```

### 例 2：Python 应用（含依赖分层）

`app.py`：

```python
from flask import Flask
app = Flask(__name__)
@app.route('/')
def hi(): return "Hello from Docker!\n"
app.run(host='0.0.0.0', port=5000)
```

`requirements.txt`：`flask`

`Dockerfile`（注意依赖先拷、再拷源码以保缓存）：

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python","app.py"]
```

```bash
docker build -t py-demo:1.0 .
docker run -d -p 5000:5000 py-demo:1.0
```

### 例 3：Java / Spring Boot（多阶段构建）

源码 `DemoApplication.java` 用 Maven 构建出 `target/app.jar`。

`Dockerfile`：

```dockerfile
# 阶段一：用 Maven 编译
FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /src
COPY pom.xml .
RUN mvn -q dependency:go-offline      # 缓存依赖层
COPY src ./src
RUN mvn -q package -DskipTests

# 阶段二：用 JRE 运行，极小
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY --from=build /src/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java","-jar","app.jar"]
```

```bash
docker build -t java-demo:1.0 .
docker run -d -p 8080:8080 java-demo:1.0
```

> 最终镜像不带 Maven/ JDK 编译器，仅含 JRE，体积从 700MB+ 降到 200MB 出头。

### 例 4：静态前端（Nginx 托管）

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci && COPY . . && npm run build

FROM nginx:1.27-alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```

### 构建过程观察与排错

```bash
docker build -t demo:1.0 . --no-cache   # 不用缓存，强制全量重建
docker build -t demo:1.0 . --progress=plain   # 看详细步骤
docker history demo:1.0                    # 看每层大小
```

常见坑：

- `COPY` 路径写错 → 报 `no such file`；注意相对 WORKDIR。
- 忘了 `.dockerignore` 把 `node_modules` 打进去 → 构建慢且覆盖正确依赖。
- 应用监听 `127.0.0.1` 而非 `0.0.0.0` → 映射了端口也访问不到，务必 `0.0.0.0`。
