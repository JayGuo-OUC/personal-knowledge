## 当前技能

## 如何新增

当某类任务你已做 ≥3 次、且步骤可模板化时，新建 `skills/<名称>.md`，含：**适用场景、输入、步骤、注意事项、示例**。判定标准详见 [[CLAUDE]] 第七节。
